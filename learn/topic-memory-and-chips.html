Plain-English glossary

Memory wall
The point where a processor can calculate faster than memory can deliver data to it.
HBM (high-bandwidth memory)
Stacked memory chips placed right next to an AI processor to feed it data quickly.
GPU / CPU
A GPU does very many simple calculations at once; a CPU handles general logic and coordination. AI agents use both.
Custom silicon
A chip a company designs for its own workload instead of buying a general-purpose one.
Training / inference
Training builds a model; inference is using it to answer a request.
Local (edge) AI
Running a model on your own device rather than in a remote data centre.

The question still open

Unresolved. If new chip designs change how much memory each unit of computing needs, does the memory bottleneck move or just change shape?
